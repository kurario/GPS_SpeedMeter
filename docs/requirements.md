# GPSスピードメータ 要求仕様

## 1. 文書の位置づけ

本書は、軽自動車の耐久レースにおいて、ピットロード制限速度の超過を防ぐための
GPSスピードメータの要求仕様案である。実装着手前の議論用ドラフトであり、
未決事項は「要確認」として明示する。

本装置は運転者の速度管理を補助するものであり、主催者の計測装置や車両の
スピードメータを代替せず、速度超過を完全に防止することを保証しない。

## 2. 目的

- ピットロード走行中、運転者が前方から大きく視線を外さずに現在速度と警告状態を認識できる。
- 設定されたピットレーン制限速度に到達した時点を、表示と音で明確に通知する。
- 車速によりピットレーンモードとレースモードを自動的に切り替え、レースモード中は
  ピット速度警告を出さない。
- GNSS測位が無効または信頼できない場合に、速度表示を有効値のように見せない。
- レース現場で短時間に起動・確認・設定でき、走行中の誤操作を起こしにくくする。

## 3. 対象ハードウェア

| 機器 | 用途・前提 |
| --- | --- |
| M5Stack Basic V2.7 | ESP32、320×240 LCD、内蔵スピーカー、物理ボタン3個を使用する |
| M5Stack用 GPS Module V2.1 | AT6668、NMEA 0183 v4.1、UART 115200 bps、最大10 Hz更新を使用する |
| M5Stack Battery Bottom 黒 110 mAh V1.1 | 補助電源として使用する |
| 外部GNSSアンテナ | GPS Module V2.1付属品を、車外または良好な受信位置に固定する |
| USB電源 | レース中の主電源候補。車両電源から安定化した5 Vを供給する |

### 3.1 ハードウェア上の制約

- GPS Module V2.1のDIPスイッチは、Basicとの標準的な組み合わせでUARTを
  `GPS TX → ESP32 G16 (RX)`、`GPS RX ← ESP32 G17 (TX)` に設定する。
  GPS Module基板上の表示では`TXD → G17`と`RXD → G16`だけをONにし、
  PPSおよびほかのTXD/RXD選択肢はOFFにする。
- ESP32のG12はストラッピングピンのため、GPS Module側でG12を選択しない。
- BasicではG25が内蔵スピーカーと共用されるため、GPS Module側でG25を選択しない。
- 内蔵110 mAh電池とBattery Bottom 110 mAhだけでレース全時間を賄う前提にはせず、
  USB給電断時のバックアップとして一定時間動作できることを実測する。
- 車両への固定方法、アンテナ配線、電源配線は、振動、脱落、視界妨害、
  操作妨害がないことを実車で確認する。

## 4. 利用シナリオ

1. ピット作業者が装置を車両に固定し、外部アンテナと電源を接続する。
2. 電源投入後、装置は自己診断とGNSS捕捉を行う。
3. ピットアウト前に、運転者またはピット作業者が測位有効、警告音、
   設定速度を確認する。
4. 装置は起動時にピットレーンモードとなり、ピットロードでは運転者が
   大きな速度表示と色を確認する。
5. 設定速度40 km/hに到達した時点で、強い表示と警告音で通知する。
6. コースイン後、設定速度以上の状態が設定時間継続するとレースモードへ移行し、
   ピット速度警告を停止する。
7. ピットイン時、設定速度以下の状態が設定時間継続するとピットレーンモードへ戻り、
   ピット速度警告を再び有効にする。
8. GNSS速度が利用不能になった場合は、速度値を無効表示に切り替え、
   専用の異常通知を行う。

## 5. 機能要求

### 5.1 GNSS受信・速度算出

| ID | 要求 |
| --- | --- |
| FR-GPS-001 | UART 8N1でGPS Module V2.1のNMEA文を受信する。起動時にESP32 UARTのエッジ計測でボーレートを推定してNMEA受信を検証する。推定できない場合は製品情報照会を460800、230400、115200、57600、38400、19200、9600、4800 bpsで順に送信し、チェックサム正常な応答を検出した速度を自動選択する。通信確立後はCASICコマンドで車載動作モデル、2D/3D自動測位、推測航法0秒、100 ms/10 Hz更新を設定し、各設定のACKと再読出し値の一致を確認する。確認に失敗した場合は速度受信へ進まず再試行する。RMC/GGA出力要求を含むGPS設定は電源サイクル中だけ適用し、GPSモジュールのFLASHへ保存しない。未検出時は走査を繰り返す。 |
| FR-GPS-002 | 少なくともRMC文の測位状態、対地速度、UTCを解析する。必要に応じてGGA/GSA文から測位品質、衛星数、HDOPを取得する。 |
| FR-GPS-003 | 対地速度をkm/hに変換する。画面には整数だけを表示するが、警告判定とモード判定には丸め前の速度を使用する。 |
| FR-GPS-004 | NMEAチェックサム不正、測位無効、受信タイムアウト、値域外データを有効速度として扱わない。 |
| FR-GPS-005 | 速度サンプルの時刻と鮮度を管理し、最後の有効値を無期限に表示しない。タイムアウト値の初期案は1.0秒とする。 |
| FR-GPS-006 | 最大10 Hzの入力を取りこぼさず処理し、警告判定は新しい有効速度サンプルごとに実行する。 |
| FR-GPS-007 | 瞬間的な測位ノイズによる警告の点滅を抑える。ただし平滑化によって警告が遅れないよう、フィルタ方式と最大遅延を実測で決定する。 |

### 5.2 ピットレーン／レースモード

Tab5版Kuruma-Loggerと同様に、速度しきい値と継続時間を組み合わせた状態機械で
モードを自動切替する。速度しきい値を一度横切っただけでは切り替えず、
設定された継続時間を満たした場合だけ遷移する。

| 現在モード | 遷移条件 | 遷移先 | 初期値 |
| --- | --- | --- | --- |
| ピットレーン | 有効なGNSS速度がレース移行速度以上の状態を、レース移行時間継続 | レース | 60 km/h以上を3秒 |
| レース | 有効なGNSS速度がピット復帰速度以下の状態を、ピット復帰時間継続 | ピットレーン | 40 km/h以下を3秒 |

| ID | 要求 |
| --- | --- |
| FR-MODE-001 | 起動時のモードは常にピットレーンモードとする。 |
| FR-MODE-002 | レース移行速度以上の有効速度がレース移行時間継続した場合、レースモードへ移行する。 |
| FR-MODE-003 | ピット復帰速度以下の有効速度がピット復帰時間継続した場合、ピットレーンモードへ移行する。 |
| FR-MODE-004 | 遷移条件を満たさない有効速度を受信した場合、その方向の継続タイマーをリセットする。 |
| FR-MODE-005 | GNSS速度が無効または古い場合は両方の継続タイマーをリセットし、速度値だけを根拠にモードを切り替えない。 |
| FR-MODE-006 | レースモード中はCAUTION、WARNING、およびそれらの反復警告音・警告点滅を無効にする。 |
| FR-MODE-007 | レースモードからピットレーンモードへ移行した直後から、現在速度に応じたピット速度警告判定を再開する。 |
| FR-MODE-008 | 現在のモードを画面上で常時識別できるようにする。モード遷移時は短時間の表示で通知する。 |
| FR-MODE-009 | 自動モード切替機能を設定で無効化できる。無効時の固定モードはレースモードとする案を基本とし、確定前に安全性を確認する。 |
| FR-MODE-010 | ピット作業時の確認用として、停止中にピットレーンモードへ手動復帰できる操作を設ける。走行中の偶発操作を防止する。 |
| FR-MODE-011 | 電源再投入時に直前のランタイムモードを復元せず、必ずピットレーンモードから開始する。 |

自動復帰は車速だけを使用するため、低速コーナー、黄旗、セーフティカー、渋滞と
ピット進入を完全には区別できない。ピット復帰速度と継続時間は、対象コースの
最低レース速度およびピット入口から速度計測地点までの所要時間を基に調整する。

### 5.3 警告判定

ピットレーンモード中は、注意開始速度と警告開始速度を直接設定する。
初期値は35 km/hからCAUTION、40 km/hからWARNINGとする。
レースモード中はピット速度警告を出さない。

| 状態 | 判定 | 表示 | 音 |
| --- | --- | --- | --- |
| NORMAL | 注意開始速度未満 | 緑または白 | なし |
| CAUTION | 注意開始速度以上、警告開始速度未満 | 黄 | 短い間欠音 |
| WARNING | 警告開始速度以上 | 赤、必要に応じ点滅 | ピットロード制限速度未満では明確な反復音、制限速度以上では連続したNG音 |
| GPS INVALID | 速度を信頼できない | `---` と「GPSなし」 | 一度測位した後に喪失した時点で、モードを問わず1回だけ専用異常音 |

| ID | 要求 |
| --- | --- |
| FR-ALT-001 | 「ピットロード制限速度」「注意を始める速度」「警告を始める速度」を1 km/h刻みで直接設定できる。 |
| FR-ALT-002 | 設定値は `注意開始速度 <= 警告開始速度 <= ピットロード制限速度` の関係を保つよう補正する。注意開始速度と警告開始速度を同じ値にした場合はCAUTIONを使用せず、その速度から直ちにWARNINGとする。 |
| FR-ALT-003 | CAUTIONとWARNINGに別の表示色・音パターンを割り当てる。 |
| FR-ALT-004 | しきい値付近の状態往復を抑えるヒステリシスを持つ。解除側ヒステリシスの初期案は2 km/hとする。 |
| FR-ALT-005 | WARNINGへの遷移は、平滑化済み速度だけでなく、明らかな単発超過サンプルも考慮する。具体条件は実車データで決定する。 |
| FR-ALT-006 | 内蔵スピーカーを使用し、車内騒音、ヘルメット、エンジン回転中でも認識可能な音量・音程であることを実車試験で確認する。 |
| FR-ALT-007 | 起動後に警告音のセルフテストを行い、ボタン操作で再試験できる。 |
| FR-ALT-008 | ミュートを設ける場合でも走行中に偶発的に無音化しない操作とし、ミュート中は常時画面表示する。 |
| FR-ALT-009 | CAUTIONおよびWARNINGはピットレーンモード中だけ出力する。レースモードへ移行した時点で発音・点滅状態をリセットする。 |
| FR-ALT-010 | 初期設定では注意開始速度を35 km/h、警告開始速度を40 km/hとし、丸め前のGNSS速度が各設定速度以上になった最初の有効サンプルでCAUTIONまたはWARNINGへ遷移する。 |
| FR-ALT-011 | ピットレーンモード中、丸め前の有効なGNSS速度がピットロード制限速度以上の間は、設定された警告音程で連続したNG音を鳴らす。制限速度未満への低下、レースモードへの移行、GNSS速度の無効化、またはピット警告音の無効化で直ちに停止する。 |

### 5.4 画面表示

| ID | 要求 |
| --- | --- |
| FR-UI-001 | 走行画面の中心に現在速度を小数なしの大型整数で表示し、単位`km/h`を併記する。 |
| FR-UI-002 | 画面全体または広い帯の色でNORMAL、CAUTION、WARNING、GPS INVALIDを区別する。 |
| FR-UI-003 | 設定中の制限速度とGNSS状態を常時確認できる。 |
| FR-UI-004 | GNSS未捕捉時、速度欄を`---`とし、捕捉待ちであることを表示する。 |
| FR-UI-005 | 直射日光下、夜間、振動中、ヘルメット着用時を想定した視認性を実車で確認する。 |
| FR-UI-006 | 走行中画面は情報を絞り、設定画面への意図しない遷移を防ぐ。 |
| FR-UI-007 | ピットレーンモードでは速度警告を最優先表示し、レースモードでは警告色を使用せず、速度とレースモード表示に限定する。 |
| FR-UI-008 | レースモード中もGNSS異常を視覚表示する。異常音は喪失時に1回だけとし、反復しない。 |
| FR-UI-009 | Kuruma-LoggerのM5Stack CoreS3SE向けGUIを参考に、黒基調のダークテーマ、太い数字、状態色のアクセントという視覚階層を採用する。320×240画面では装飾的なゲージを置かず、速度を画面高の大半を占める最大要素として中央表示する。通常時の補助情報は小さな走行モード表示、ピット制限速度、単位だけとし、警告またはGNSS異常の情報は発生時だけ表示する。 |

### 5.5 設定・操作

| ID | 要求 |
| --- | --- |
| FR-CFG-001 | 3個の物理ボタンでピットレーン制限速度、注意開始速度、警告開始速度、モード遷移条件、音量、画面輝度を設定できる。 |
| FR-CFG-002 | 設定値をNVSに保存し、電源再投入後に復元する。 |
| FR-CFG-003 | 初期制限速度は40 km/hとする。設定可能範囲は20～80 km/h、1 km/h刻みを基本とする。 |
| FR-CFG-004 | 起動時に制限速度を明示し、意図しない設定で走行を開始しにくくする。 |
| FR-CFG-005 | 設定変更は停止中に限定する案を基本とする。GNSS無効時の変更許可条件は要検討とする。 |
| FR-CFG-006 | 工場初期値への復帰操作を提供し、誤操作防止のため長押しまたは確認操作を要求する。 |
| FR-CFG-007 | 設定可能なパラメータと初期値を次表のとおりとする。値域と相互関係を検証し、不正な組み合わせを保存しない。 |
| FR-CFG-008 | 設定と通常操作は本体の3個の物理ボタンを主手段とし、スマートフォンやWeb画面を必須としない。 |
| FR-CFG-009 | 設定画面はマイコンやGNSSの専門知識を前提とせず、各項目に日本語の名称と平易な説明文を表示する。音量と明るさは利用者が理解しやすい百分率で表示し、オン／オフ、増減、次項目、保存終了の操作も日本語で案内する。 |

| パラメータ | 初期値 | 設定範囲 | 備考 |
| --- | ---: | ---: | --- |
| ピットレーン制限速度 | 40 km/h | 20～80 km/h | 大会規則上の制限速度 |
| 注意を始める速度 | 35 km/h | 20 km/h～警告開始速度 | CAUTIONを開始する実車速 |
| 警告を始める速度 | 40 km/h | 注意開始速度～制限速度 | WARNINGを開始する実車速。同値ならCAUTIONを使用しない |
| 警告解除ヒステリシス | 2 km/h | 0～10 km/h | しきい値付近のチャタリング防止 |
| レース移行速度 | 60 km/h | 20～200 km/h | ピット警告速度より大きい値とする |
| レース移行時間 | 3秒 | 1～30秒 | 連続して条件成立した時間 |
| ピット復帰速度 | 40 km/h | 0～100 km/h | レース移行速度未満とする |
| ピット復帰時間 | 3秒 | 1～300秒 | コース低速区間での誤復帰を防ぐ |
| ピット警告音 | 有効 | 有効／無効 | 無効時は画面に常時表示 |
| ピット警告点滅 | 有効 | 有効／無効 | CAUTIONとWARNINGを区別 |
| 警告音量 | 要実機調整 | 0～255相当 | M5Unifiedの有効範囲に合わせる |
| CAUTION音程 | 1200 Hz | 400～6000 Hz | WARNINGと識別可能にする |
| WARNING音程 | 3200 Hz | 400～6000 Hz | CAUTIONと識別可能にする |
| 画面輝度 | 要実機調整 | ハードウェア範囲内 | 昼夜のプリセットも検討 |

設定画面には、計算後のCAUTION速度とWARNING速度も表示し、運用者が実際の
警告開始速度を確認できるようにする。

### 5.6 起動・異常処理

| ID | 要求 |
| --- | --- |
| FR-SYS-001 | 電源投入から5秒以内に起動画面と初期化状態を表示する。GNSS捕捉完了を起動画面表示の条件にしない。 |
| FR-SYS-002 | LCD、スピーカー、設定読出し、UART受信状態を起動時に確認する。 |
| FR-SYS-003 | GNSS未捕捉、NMEA受信断、設定破損、電源低下を区別して表示する。 |
| FR-SYS-004 | 設定破損時は安全側の初期値を使用し、異常を表示する。 |
| FR-SYS-005 | タスク停止や長時間ブロックを検出するため、ESP-IDFのウォッチドッグを使用する。 |
| FR-SYS-006 | 予期しない再起動後も自動的に通常動作へ復帰し、再起動した事実を起動時に通知する。 |
| FR-SYS-007 | 起動後に一度も有効測位を得ていない間はGNSS異常音を鳴らさない。一度有効測位を得た後にGPS INVALIDへ遷移した時点で1回だけ鳴らし、測位が復帰するまで再発音しない。 |
| FR-SYS-008 | 起動画面は黒基調のシンプルなデザインとし、タイトル「M5Stack GPS Speed Meter」、サブタイトル「by kurumario」、およびGNSS初期化中であることを2秒間表示する。 |

## 6. 非機能要求

| ID | 要求 |
| --- | --- |
| NFR-001 | ESP-IDF上でC/C++により実装し、FreeRTOSタスクとして動作させる。 |
| NFR-002 | GNSS受信処理、警告判定、画面・音出力、設定保存を分離し、ハードウェア依存部を交換可能にする。 |
| NFR-003 | GNSSサンプル受信からWARNING出力開始までの目標遅延を100 ms以下とする。GPS自体の更新周期・測位遅延は別に評価する。 |
| NFR-004 | 10 Hz GNSS入力、画面更新、警告音を同時実行しても、NMEA受信欠落やウォッチドッグリセットを起こさない。 |
| NFR-005 | 電源瞬断、UART断、無効NMEA、NVS破損を与えても、誤った有効速度を継続表示しない。 |
| NFR-006 | 外部5 V給電で8時間連続動作できることに加え、満充電から内蔵電池だけで最低30分、目標60分の連続動作を確認する。30分を満たせない場合は画面輝度・更新頻度等を見直し、実測時間を運用上明示する。 |
| NFR-007 | 使用温度、振動、電源ノイズは実車環境で評価する。Basic V2.7の公称範囲を超える環境では使用しない。 |
| NFR-008 | 走行判定や警告判定の純粋ロジックはホスト側単体テスト可能にする。 |
| NFR-009 | UART受信断、測位無効、状態遷移、再起動理由をシリアルログに記録できる。個人位置情報を含む走行ログ保存は初期スコープ外とする。 |
| NFR-010 | ピットレーン／レースモード判定はUI、FreeRTOS、M5Unifiedに依存しない純粋な状態機械として実装する。 |
| NFR-011 | 20～80 km/hの定速域で、基準計測器に対する速度誤差を中央値2 km/h以下、95パーセンタイル3 km/h以下とする。装置内の警告処理遅延は100 ms以下とし、GNSS受信機を含む総遅延は実車試験で1秒以下を目標とする。 |

## 7. ソフトウェア構成案

要求を満たす最小構成として、以下のFreeRTOSタスクまたはコンポーネントを想定する。

| 構成要素 | 責務 |
| --- | --- |
| GNSS UART Driver | UART受信、リングバッファ、受信タイムアウト検出 |
| NMEA Parser | チェックサム検証、RMC/GGA/GSA解析、速度・品質スナップショット生成 |
| Racing Mode Domain | 車速と継続時間によるピットレーン／レースモード状態機械 |

| UI Task | LCD描画、ボタン読取り、設定画面 |
| Alert Output | スピーカーの音パターン再生、セルフテスト |
| Settings Store | NVS読書き、既定値、整合性確認 |
| System Monitor | ウォッチドッグ、起動理由、電源・タスク状態監視 |

タスク間はキューまたは最新値スナップショットで接続し、GNSS受信処理をLCD描画や
音再生でブロックしない。

## 8. Kuruma-Loggerからの再利用候補

Kuruma-Loggerはu-blox/UBXを中心にしており、本機のAT6668/NMEAとプロトコルが異なるため、
GPS初期化・UBXパーサをそのまま流用しない。一方、次は設計またはコードの再利用候補である。

- ESP-IDFコンポーネント分割とcomposition rootの考え方
- FreeRTOSタスク生成、キュー、ウォッチドッグの運用規約
- M5Unified/M5GFXを使ったLCD、ボタン、スピーカーのハードウェア抽象化
- NVS設定ストア、設定スキーマ、初期値・破損時処理
- GPSスナップショットの鮮度無効化、状態集約、構造化ログ
- `domain/policies/racing_meter.hpp`のピットレーン／レース状態機械と
  `tests/test_domain_racing_meter.cpp`の継続時間・鮮度・ヒステリシステスト
- 純粋な判定ロジックをホスト単体テストする構成

再利用時はKuruma-Loggerのライセンス、依存関係、対象ESP32世代の差を確認し、
必要最小限を移植する。

## 11. 確定事項と残課題

### 11.1 確定事項

- ピットレーン制限速度の初期値は40 km/hとし、変更可能にする。
- 注意開始速度と警告開始速度を直接設定し、初期値はそれぞれ35 km/h、40 km/hとする。
- モード切替の初期値は、60 km/h以上を3秒でレースモード、
  40 km/h以下を3秒でピットレーンモードとする。
- 外部5 V給電を主電源としつつ、内蔵電池だけでも一定時間動作可能にする。
- 警告音は内蔵スピーカーを使用する。
- 設定・操作は本体の物理ボタンを主手段とする。
- 速度表示は整数のみとする。
- GNSS異常音は、一度測位した後の喪失時にモードを問わず1回だけ鳴らす。
- GNSS精度・遅延はNFR-011およびAT-008の推奨基準で検証する。

### 11.2 残課題

- 黄旗、セーフティカー、低速コーナーでピットレーンモードへ誤復帰しない条件はTBD。
- 取付位置、視認距離、昼夜の画面輝度、グローブ着用時の操作性は実車で決定する。
- 内蔵電池での実際の連続稼働時間と、最低30分・目標60分の達成可否を実測する。
